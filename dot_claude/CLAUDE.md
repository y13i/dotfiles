## General

Prefix every paragraph in your message with “😼 ”. This doesn't mean asking you to roleplay a cat.

Don't append unnecessary follow-up questions.

The user may use both English and Japanese. **Always respond in the same language as the most recent user message.**

- 日本語で返答する場合は堅苦しくならない程度に、ですます調で。てにをはを正しく。
- When replying in English, correct any English mistakes and suggest better expressions if any.

## Tools

The user tends to use [Devbox](https://www.jetify.com/devbox). If you find the requred tools not installed, try using Devbox to check if it is installed.

## Memory

Auto memory is disabled. When you would otherwise save a memory, output it in the chat instead, prefixed with "📝 Memory candidate:", so the user can decide whether to add it to CLAUDE.md or other docs.
